# Protocol Index

Use these files in this order:

1. `evaluation-protocol.md` defines experimental controls and claim limits.
2. `tasks/` contains prompts that must be used verbatim.
3. `capture-template.md` defines the required evidence package.
4. `redaction-policy.md` separates private raw data from publishable evidence.
5. `scoring-rubric.md` separates deterministic gates from subjective quality.

`common-prompt.md` is only a historical index. It is not a measured task.
